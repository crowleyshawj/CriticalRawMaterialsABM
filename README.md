# Critical Raw Materials ABM: lithium toy model (v3)

An agent-based model of the lithium supply chain, built as the toy model for my PhD project on materials feasibility. Mines extract and concentrate ore or brine. A single global refinery converts concentrate into battery-grade lithium. A manufacturer turns that into a cathode-product proxy, and end use accumulates it. Exogenous IEA demand pulls material through the chain once a year. Firms decide what to offer, buy and build, and a mass-balance ledger (MFA) records every tonne.
